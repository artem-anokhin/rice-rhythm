# Rice Rhythm — запуск MVP (Ubuntu)

Два скрипта:
1. `fetch_nisar.py` — забирает с ASF кусок снимков NISAR GCOV по нашему участку (только слои HH и HV) и сохраняет `data/stack.nc` + картинки по датам и `data/season.gif`.
2. `analyze_fields.py` — считает «ритм» каждого поля, раскрашивает поля по режиму, делает графики, сравнение двух полей, карту `out/map.html` и итоговые цифры `out/summary.txt`.

## 0. Аккаунт Earthdata (5 минут, без него данные не скачать)

1. Зарегистрироваться: https://urs.earthdata.nasa.gov/users/new
2. Войти один раз на https://search.asf.alaska.edu и попробовать скачать любой маленький файл (например, превью) — так принимаются условия использования данных.
3. На https://urs.earthdata.nasa.gov → **Generate Token** → скопировать токен.

## 1. Установка

```bash
cd rice_rhythm
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Данные NISAR

```bash
export EARTHDATA_TOKEN="вставьте_токен"
python fetch_nisar.py --list-only     # сначала просто список дат трека 078
python fetch_nisar.py                 # читает только нужный кусок каждого снимка
```

Если потоковое чтение выдаёт ошибки — запасной путь (качает файлы целиком, ~2 ГБ каждый):
```bash
python fetch_nisar.py --download
```

Участок, трек и даты меняются вверху `fetch_nisar.py` (блок «НАСТРОЙКИ»).

## 3. Контуры полей

1. Открыть https://geojson.io, переключить подложку на спутник (Satellite).
2. Найти Жалагаш, нарисовать прямоугольники по 30–50 рисовым чекам (инструмент «Draw Polygon» / «Rectangle»).
3. Save → GeoJSON → положить файл как `rice_rhythm/fields.geojson`.

Если не успеваете — запустите без файла: участок разрежется на квадраты 300 м (план Б).

## 4. Анализ и карта

```bash
python analyze_fields.py            # графики, карта, сводка
python analyze_fields.py --sound    # + звук ритма каждого поля (out/sound/*.wav)
```

Открыть `out/map.html` в браузере → клик по полю показывает его график → делать скриншоты.

## 5. Подбор порогов

Вверху `analyze_fields.py` блок «ПОРОГИ». Посмотрите 5–10 графиков в `out/charts/` и поправьте:
- `DROP_DB` — на сколько дБ должен упасть HH, чтобы считать это сбросом воды;
- `RISE_DB` — на сколько должен вырасти обратно;
- `NOT_RICE_HV_MAX` — ниже какого максимума HV поле считаем «не рис».

Пересчёт занимает секунды — можно крутить сколько нужно.

## Скриншоты для слайдов

| Файл | Слайд |
|---|---|
| `out/map.html` | Карта региона: поля раскрашены по режиму |
| `out/charts/<поле>.png` | Ритм одного поля |
| `out/compare.png` | Два поля: «ровное» и «пульсирующее» |
| `data/season.gif` | Анимация сезона по радару |
| `out/summary.txt` | Итоговые цифры |
